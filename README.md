# Spotify SQL Analytics

A SQL-based music streaming analytics project designed using the Spotify 2023 dataset to analyze artist performance, streaming trends, platform popularity, and music engagement metrics through relational database design and advanced SQL queries.

---

## Project Overview

This project focuses on designing and querying a relational music streaming database using Spotify 2023 data.

The project includes:

* relational database schema design
* SQL-based analytics
* streaming performance analysis
* cross-platform music insights
* ranking and aggregation queries
* exploratory data analysis
